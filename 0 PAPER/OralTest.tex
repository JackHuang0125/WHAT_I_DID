\section{問題與目的}

\begin{frame}
  \centering
  \huge{問題與目的}
\end{frame}

\begin{frame}{\textbf{研究目的}}
  \begin{itemize}
    \item 若整體資料存在多個子群，單一模型的局部解釋可能混合不同規則。
      \item 分群後建立黑箱模型，以降低資料異質性對模型學習的干擾。
    \item 若以隨機擾動生成鄰近點，可能偏離真實資料分布，產生外插風險。
      \item 設計格子點生成方法，以控制局部擾動範圍，提升局部擬合的穩定性，並降低外插可能造成的偏誤
      \item 建立可檢視的局部刻劃模型，以作為黑箱模型在分類行為上的可解釋依據。
  \end{itemize}
\end{frame}

\begin{frame}{\textbf{黑箱模型}}
  \begin{itemize}
    \item Skicit-learn: XGBClassifier
    \item 評估方式：五折交叉驗證
    \item 僅在訓練集執行 SMOTE，每一折當測試集輸出機率值
    \item 用 Accuracy(ACC)、False Alarm Rate(FAR)、ROC-AUC 評估群間是否有差異
  \end{itemize}
\end{frame}

\begin{frame}{\textbf{局部刻劃方法}}
    \vspace{0.5cm}
  % 不直接在原樣本附近做隨機擾動，而是以
    \begin{itemize}
    \item 在群 c 內，取滿足 $|\hat{p}-0.5|\le 0.05$ 的樣本集合，記為 $S^c_n$
    \item 對 $S^c_n$ 內的樣本特徵向量取平均，定義群內中心點為 $$x^c_\mathbf{center}=\frac{1}{|S^c_n|}\sum_{i\in S^c_n}\mathbf{x}_i=(x^{(c)}_1,\dots,x^{(c)}_p)$$ 
    \item 以中心點為基準生成格子點： $$x^{(m)}=x^c_\mathbf{center}+\delta \mathbf{m}$$ 其中 
      \begin{itemize}
        \item $\delta$ 為各維度相同的位移步長
        \item $\mathbf{m}=(m_1,\dots,m_p)$ 為位移向量，且$m_j\in\{-k,-k+1,\dots,0,\dots,k-1,k\}$
      \end{itemize}
    \item 共有 $(2k+1)^p$ 個格子點
    \end{itemize}
\end{frame}

\begin{frame}{\textbf{結果總結}}
\begin{itemize}
  \item 分群後，各群黑箱模型呈現不同的錯誤型態與可分類程度。
  \item 以決策邊界附近樣本建立中心點，可聚焦於模型判斷最不明確的局部區域。
  \item 結構化格子點可在可控制的鄰域內近似黑箱輸出，避免隨機擾動造成的外插偏誤。
  \item 群內局部刻劃模型可將黑箱決策轉為具體的局部重要特徵與方向性資訊。
\end{itemize}
\end{frame}

\begin{frame}{\textbf{結論}}
\begin{itemize}
  \item 本研究提出一套適用於高維、缺失嚴重且類別不平衡製程資料的分析流程。
  \item 透過先分群再於群內建模，可降低異質性對黑箱學習與局部解釋的干擾。
  \item 透過中心點與格子點設計，可在較低外插風險下建立局部線性刻劃模型。
  \item 研究結果顯示，不同子群對應不同的黑箱局部決策結構，分群式局部刻劃具分析價值。
\end{itemize}
\end{frame}
