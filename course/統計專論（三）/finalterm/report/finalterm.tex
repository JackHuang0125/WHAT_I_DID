\begin{frame}{老師建議後的修正方向}
\begin{itemize}
  \item 原始資料先切分 Phase I 與 Phase II。
  \item 只在 Phase I 做前處理：刪除缺失值，並用 3 倍 IQR 移除離群值。
  \item Phase II 視為新取得資料，不做離群值刪除。
  \item \(x_{297}\) 嚴重右偏，不再用常態型 EWMA、CUSUM、CPD 界線做 Phase II 管制圖。
  \item Individuals Shewhart 改用 Gamma 上界，下界設為 0。
  \item Phase II 主要以整段 RS/P 無母數診斷檢查 level 與 scale。
\end{itemize}
\end{frame}

\begin{frame}{結論}
\begin{itemize}
  \item 修正後流程符合 Phase I/Phase II 監控：先切資料，只清理 Phase I。
  \item \(x_{297}\) 右偏且非負，因此不用常態 3-sigma 對稱界線。
  \item Gamma Individuals Shewhart 給出 UCL = 7338.84，Phase II 有 23 筆超界。
  \item 整段 Phase II RS/P 尚未在 0.05 水準顯著，但 level 診斷接近顯著。
  \item 後續建議針對 Phase II 後段做滑動視窗或分批 RS/P 診斷。
\end{itemize}
