針對局部刻劃模型在大量候選點與高維特徵下的計算負擔，
實作分批式線性迴歸估計流程。

傳統 OLS 需一次生成並儲存完整候選樣本矩陣；
本專案改以 streaming batch 方式逐批處理資料，
累積 X'X、X'y、y'y 等 sufficient statistics，
最後再求解局部線性模型係數與 R²。

在模擬高維製程資料情境下
（200 萬筆候選點、500 個特徵、batch size = 100,000），
相較於傳統一次性 OLS，
峰值記憶體使用量由 22,934.43 MB 降至 769.07 MB，
約降低 96.65%；執行時間由 68.95 秒降至 16.75 秒，
約降低 75.70%。

兩種方法的 R² 差異僅 2.24e-08，
表示優化後仍能維持近乎一致的迴歸結果。
